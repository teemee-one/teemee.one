# Projects

This directory contains open-source projects, tools, and experiments built with or for AI.

## What's Here

Each project is a complete, self-contained tool designed to:
- Solve real problems
- Demonstrate AI capabilities
- Experiment with new ideas
- Support the teemee.one community

## Exploring Projects

Each project has its own:
- **README.md** - Overview, installation, and usage
- **docs/** - Detailed documentation
- **src/** or equivalent - Source code
- **tests/** - Test suite
- **LICENSE** - License (compatible with teemee.one's MIT license)

## Project Standards

All projects in teemee.one should:

✓ Have clear documentation
✓ Include working examples
✓ Be tested and maintained
✓ Use compatible licenses (MIT or similar)
✓ Follow the contribution guidelines in [CONTRIBUTING.md](../CONTRIBUTING.md)
✓ Be genuinely useful or educational

## Contributing a Project

To add your project to teemee.one:

1. **Prepare your project** - Ensure it has documentation, tests, and a clear license
2. **Create a directory** - `projects/your-project-name/`
3. **Include required files** - README.md, LICENSE, proper documentation
4. **Open a PR** - Submit for review with description of the project

See [CONTRIBUTING.md](../CONTRIBUTING.md) for detailed guidelines.

## Project Ideas

Areas where we welcome projects:

- **AI Integration Tools** - Simplify working with AI APIs
- **Prompt Management** - Tools for organizing and versioning prompts
- **Data & Analysis** - Tools for analyzing AI outputs or your own data
- **Educational** - Learning resources and interactive tutorials
- **Productivity** - Tools that enhance workflow with AI
- **Experimentation** - Novel approaches to using AI tools
