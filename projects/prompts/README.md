# Prompts

This directory contains a growing library of AI prompts organized by use case and category.

## Categories

- **writing/** - Content creation, editing, storytelling, copywriting
- **analysis/** - Data analysis, research synthesis, evaluation, critical thinking
- **coding/** - Programming assistance, debugging, code review, refactoring
- **creativity/** - Brainstorming, ideation, innovation, artistic exploration
- **research/** - Literature review, research methodology, hypothesis generation

## How to Use

Browse by category to find prompts relevant to your task. Each prompt includes:
- Clear description of purpose and use case
- The actual prompt template
- Example inputs and outputs
- Tips for best results
- Model compatibility notes

## Contributing

Found a prompt that works great? Have a new one to share?

1. Create a markdown file in the appropriate category
2. Follow the format outlined in `STRUCTURE.md`
3. Submit a pull request with your addition

See [CONTRIBUTING.md](../CONTRIBUTING.md) for detailed guidelines.

## Format Template

```markdown
# Prompt Title

**Category:** [category]
**Difficulty:** [beginner/intermediate/advanced]
**Models:** [GPT-4, Claude 3, Llama 2, etc.]
**Use Case:** [When and why to use this prompt]

## Prompt

[The actual prompt text - this is what you'll copy and use]

## Example Input

[Sample input to show how to use this]

## Example Output

[Expected output or result]

## Tips

- Specific tips for getting better results
- Model-specific considerations
- Common variations or extensions
- Related prompts

## Related Prompts

- [prompt-name.md](./prompt-name.md)
- [another-prompt.md](./another-prompt.md)
```
