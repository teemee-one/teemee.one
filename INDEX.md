## Getting Started

### As a User

1. **Clone the repository**
   ```bash
   git clone https://github.com/teemee-one/teemee.one.git
   cd teemee.one
   ```

2. **Read [USAGE.md](./USAGE.md)** - Learn how to use with your tools

3. **Browse prompts** in `/prompts` directory

4. **Try a prompt** with Claude.ai or OpenAI API

### As a Contributor

1. **Read [CONTRIBUTING.md](./CONTRIBUTING.md)** - Understand how to contribute

2. **Check [STRUCTURE.md](./STRUCTURE.md)** - Find the right directory for your content

3. **Follow guidelines** for your content type (prompts, articles, projects)

4. **Submit a pull request**

### As an AI Agent

1. **Read [AGENTS.md](./AGENTS.md)** - Comprehensive guide for agents

2. **Understand core intentions** in `/intentions`

3. **Follow workflow** and best practices

4. **Maintain quality** and seek human review when needed
